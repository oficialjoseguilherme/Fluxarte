# Diretório de documentação do sistema

Esse diretório é reponsável por armazenar os artefatos de modelagem e documentação do sistema. Ele é importante para guardar os documentos, mas principalmente para oferecer rastreabilidade e proximidade ao código.

## Conteúdo

- Diagramas 
- Modelagem do banco de dados
- Arquitetura do sistema
- Especificação de requisitos
- Registros de decisões arquiteturais
- Documentação de API's


### Os artefatos armazenados aqui devem ser desenvolvidos preferencialmente em texto para ser possível manter a rastreabilidade com granularidade máxima. Esse texto pode ser algum tipo de código, como o código Mermaid para diagramas.
